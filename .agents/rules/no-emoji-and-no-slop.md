# Zero Emoji & Anti-Slop Directive

## Core Rules
1. **NO EMOJIS**: Under no circumstances should unicode emojis be placed in UI strings, notification logs, club badges, event descriptions, speech bubbles, comments, or documentation.
2. **BRUTALIST VECTOR ICONS ONLY**: Use `BrutalistIcons`, Flutter vector `IconData`, SVG, or `CustomPainter` vector shapes.
3. **GROUNDED FOOTBALL JARGON**: Use authentic, sober, institutional football and financial terminology instead of performative AI excitement or emotional buzzwords.
